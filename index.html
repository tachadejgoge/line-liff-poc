Checking LINE LIFF SDK

ตั้งค่า LIFF ID ก่อนเริ่มใช้งาน

  1. เปิดใช้ GitHub Pages และนำ HTTPS URL นี้ไปสร้าง LIFF App ใน LINE Developers
  2. เปิดไฟล์ index.html ใน GitHub แล้วแทนค่า PASTE_LIFF_ID_HERE ด้วย LIFF ID จริง
  3. กดเปิดผ่าน LIFF URL https://liff.line.me/{LIFF_ID} จาก Rich Menu

LIFF ID เป็น public identifier ใส่ในโค้ดหน้าเว็บได้ ไม่ต้องใส่ Channel Secret หรือ Access Token

เข้าสู่ระบบ LINE เพื่อทดสอบ

ใน LINE App จะล็อกอินผ่าน LIFF ตามปกติ ส่วนเบราว์เซอร์ภายนอกอาจต้องกดปุ่มนี้ก่อน

Privacy: แสดง User ID และข้อมูลโปรไฟล์เฉพาะในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่มีการส่งข้อมูลไปเก็บในเซิร์ฟเวอร์ และไม่แสดง Token

หมายเหตุ: LINE User ID เป็นรหัสของผู้ใช้ ไม่ใช่ LIFF ID และอาจแตกต่างกันเมื่อใช้คนละ Provider
